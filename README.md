# 飞牛影视 手机版（Android）

飞牛 NAS（fnOS）影视库的第三方 Android 客户端。原画直连、原生播放器、弹幕、投屏，
数据全部读你自己 NAS 上的飞牛影视接口，不经过任何第三方服务器。

## 主要功能

- 弹幕：自建服务对接，支持本地文件。
- 原画直连：直读 NAS 文件，不走转码，拖动秒响应。
- 解码兜底：硬解优先，失败可切软解，再不行一键转码。
- 媒体浏览：继续观看、海报墙、跨库搜索与分季选集。
- 播放体验：倍速、画面比例、音轨/字幕切换、进度互通、画中画。
- 连接：局域网页直连，外网走 FN ID 中转，自带本地回环代理。

## 说明

第三方客户端，与飞牛官方无关；接口来自公开的第三方实现，官方调整后可能失效。
